# 书架、发现与推荐页面改版方案

日期：2026-10-03。状态：设计评审稿，尚未修改应用功能。

## 用户要求与现有约束

- “发现”主页面不再直接展示“漫画来源”管理卡片。
- 合并书架与下载；下载未入架作品时自动加入书架；移出书架同时删除该作品所有相关下载。
- 在书架与发现之间增加“推荐”，采用类似 App Store“App”页的内容组织与排版，按热门程度、分类和来源寻找漫画。
- 保持每端本地单机模式，支持自定义源和跨源关联。保持 macOS 15.7.7、iOS 18.5 系统不变，最低版本仍为 macOS 14、iOS 17。

## 导航与发现

顶级导航依次为：**书架 → 推荐 → 发现 → 更新**。iOS 使用底部标签栏，macOS 使用侧边栏；取消独立“下载”导航项。

“发现”以跨源搜索和已打开/已验证作品为主。“管理漫画源”“筛选搜索来源”“打开作品链接”收进工具栏入口；来源启停、重新检查、原站验证、自定义源添加保留在管理页。来源管理卡片不占用发现首页空间。

## 书架与下载的统一

书架提供“全部”“已下载”“下载中”筛选，封面卡片显示已下载章节数、当前下载状态及阅读进度。顶部显示简短下载汇总，点击进入书架内的下载管理；作品卡片也能打开该作品的下载明细。保留原有单章暂停、恢复、重试、取消、删除与离线阅读操作。

一键整部下载和单章/批量下载均采用相同规则：当内容成功进入下载队列时，将对应作品加入书架。已关联的多个来源归入原有作品，不建立重复书架卡片。自动入架不擅自开启更新关注；用户原有关注设置不受影响。

旧版已有下载但不在书架上的作品，在升级后恢复队列时自动归入书架。已取消且没有离线内容的任务不触发迁移入架。停用/删除来源的既有离线内容仍可从书架找到。

“移出书架”操作在应用内明确说明会删除该作品所有关联来源的下载，包括完成、等待、传输、暂停和失败任务。确认移出后自动执行清理，无需再逐章删除。流程先阻止该作品继续准备/入队，取消相关传输，再删除离线文件和任务/清单，最后移出书架并取消相关更新关注。若清理失败，保留可见作品并提示错误，便于重试。

保留历史、阅读进度、来源配置和作品关联；这些不属于下载内容。移出一部作品不影响其他书架作品的下载。随后主动重新下载可以重新入架。删除与入队并发时，较早的目录准备不能把已移出的作品重新加回来。

## 推荐首页的内容与排版

采用 App Store“App”页的版式：大标题、顶部横向精选卡片、主题分区、紧凑漫画列表、分类与来源专栏入口。保留追漫现有配色和原生控件，不使用网页嵌入替代漫画列表。

建议从上至下展示：

1. **推荐**：更新时间及刷新按钮；初次加载、缓存内容与失败状态明确呈现。
2. **热门看板**：大封面推荐卡片，显示作品名、来源、榜单名称和进入作品详情按钮。取自来源真实热门/人气榜，避免把最近更新直接标为热门。
3. **大家在看**：各来源热门榜的漫画列表，保留原站顺序和来源标识；不将不同网站的指标拼成虚构的统一排行榜。
4. **按兴趣寻找**：热血、恋爱、冒险、科幻、悬疑等分类入口，分类项由当前可用来源真实提供的分类汇总。点击进入该分类专栏。
5. **分类热门**：按类别展示横向漫画列表，每项注明来源。支持“查看全部”。
6. **探索漫画源**：仅展示有可浏览内容的启用来源。点击进入来源专栏，显示该源真实分类、热门榜和作品列表。

iOS 窄屏采用横向卡片与单列/自适应列表；macOS 宽屏增加同屏卡片数量，页面最大内容宽度适度限制。作品标题允许多行，适配深色模式、动态字体和 VoiceOver。封面缺失或下载失败时显示占位，但仍能打开作品。

## 分类与来源专栏

分类专栏显示该分类可用的漫画源，并可进一步选择来源。来源专栏显示其完整可解析分类，支持分类、榜单和原站实际支持的排序/分页。切换分类后重新取得对应目录，不只过滤首页少量作品。

点击漫画复用现有作品详情、来源选择和章节页；用户继续自行决定阅读来源。不会仅凭同名把不同作品自动合并。英文原创来源保留语言标识。

## 推荐数据的真实性与访问方式

直接通过各源的正常公开页面或公开接口读取分类和榜单，沿用现有请求调度、访问上下文与解析器绑定。新增分类/推荐能力与已有搜索、目录、正文能力分别验证，推荐失败不破坏现有阅读。

已核实的页面例子：

- MangaBZ：首页分类链接及分类列表，https://www.mangabz.com/ 和 https://www.mangabz.com/manga-list-31-0-10/。
- DM5：首页分类及国漫/日漫/综合热门榜，https://www.dm5.com/。
- 包子漫画：首页人气榜、热门更新和分类入口，https://baozimh.org/。
- ComicFury：搜索页提供 Popularity 排序及 Genres/Tags，https://comicfury.com/search.php。

MangaDex 使用其公开 API 的实际支持字段；单系列来源 xkcd、Dinosaur Comics 展示原创系列入口。没有分类或热度指标的来源显示“来源浏览/原创系列”，不虚构分类、阅读量、评分或榜单名次。

自定义源自动复用绑定解析器已有的推荐/分类能力；仅支持正文解析的源继续可阅读，并在专栏明确说明暂无分类/榜单数据。

缓存保存成功获取的推荐及更新时间，进入页面先展示缓存并异步更新。停用/删除的源立即排除；失效来源不能继续作为当前热门数据展示。无网时可显示带时间标记的缓存。单源失败不清空其他来源的内容，提供重试入口；不绕过登录、付费、地区限制或验证码。

## 验收要求

- 顶级导航顺序正确；发现首页无来源管理卡片，但管理、筛选与链接入口可用。
- 单章、批量、整部下载自动入架；已有跨源作品不重复入架；旧下载能在书架找到。
- 移出作品删除所有相关来源下载、任务和离线清单；无关作品不受影响；在途传输和目录准备不能重新产生已删除内容。
- 推荐只使用启用、未删除且有可用数据的来源；真实分类可进入、分页可继续；榜单顺序与标签正确，普通浏览内容不伪装成热门。
- 来源失败、空结果、缺失封面、缓存过期、自定义源能力不足时有明确反馈，现有搜索、阅读和下载仍可使用。
- 运行共享检查与原生测试，双端 Release 构建；macOS 实际页面操作与离线验收；iOS 18.5 原设备覆盖安装和启动，不能将安装成功当作所有手机交互均已验收。
- 交付更新的 macOS 包与设备专用 IPA；签名有效期以实际描述文件为准；公开代码仍排除个人 Team、设备标识及签名材料。
