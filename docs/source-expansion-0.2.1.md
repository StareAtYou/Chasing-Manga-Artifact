# v0.2.1 图标与来源扩充

验证日期：2026-10-03。macOS 15.7.7，Xcode 16.4 / iOS 18.5 SDK；最低 iOS 17、macOS 14。没有升级系统。

## 黑图标

旧的 AppKit RGB 位图绘制没有写入颜色，15 个已打包的 PNG 都是黑图。本次改用 CoreGraphics 直接绘制不透明位图，保留原有青色书页图案。`scripts/make-ios-icons.swift` 可重现全部尺寸；`scripts/check-ios-icons.swift` 解码并检查实际像素，iOS 打包脚本先执行该检查。更新版本号和构建号，让系统识别新的图标资源。升级安装保留应用标识和数据。

## 漫画站

真实 Mac 探针：浏览 124 部，非人哉目录 991 章，首章 36 页、末章 4 页；首末图片均解码成功。搜索仍可能返回“安全验证”，另一次正常表单请求返回 HTTP 500/520，因此不能把原站不稳定的搜索接口声明为可用。

发现页过去将来源名作为“参与跨源搜索”开关的标签，搜索未验证时整个名称随开关灰显。现在名称、浏览列表和搜索状态分别显示，并增加直接打开来源页面的验证入口。浏览器状态保存后重新检查；保存的浏览器 User-Agent 与 Cookie 仍限于同一来源、同一 origin 的请求。正文浏览器返回验证页时明确提示完成验证；不会误报普通解析失败，也不会接受其他来源的页面。

上述内容不能证明用户报告的 iPhone 故障已复现或解决。本轮真机探针首次安装遇到设备连接超时，之后设备不可用；需连接、解锁手机后继续执行实际正文检查。

包子漫画 `.org` 与本次 HTTP 403 的 `.com` 是不同网站，本次只接入已实际验证的 `.org`。网站公开接口需要与网页一致的 Origin、Referer，目录使用 `mode=all`，避免只读取首页前后部分章节。正文加载网站自己的脚本，读取正文容器中的完整 `data-src` 列表，排除广告和占位图，不需要滚动加载每张图片。

MangaDex 使用公开 API，保留中英文别名、作者、章节语言和汉化组署名；过滤无页数、已不可用和仅有站外链接的章节。优先官方 `dataSaver` 图片；每次解析重新取得 At-Home 当前地址，页身份按章节及页号确定，CDN 改变不会破坏进度。API 目录逐页读取，错误或提前空页不会伪装成完整目录。

xkcd 使用[作者提供的 JSON 接口](https://xkcd.com/json.html)，按需请求单期真实图片，不预先获取数千张图片。

已有应用只补充缺失的内置来源 ID，不覆盖旧来源设置、书架、进度与下载。用户删除或停用的旧来源不会被重新启用。新来源仍需在实际设备与网络中检查，并通过现有自定义来源检测流程绑定适配器；不会预填“完全验证”。

以上站点有公开免费可读样本，不保证所有作品、章节、地区长期免费或可用，不绕过登录、付费、验证码或内容下架。在线探针输出见 `docs/source-probes/2026-10-03-*.json`。

## MangaDex 使用条件

按[官方 API 使用政策](https://gitlab.com/mangadex-pub/mangadex-api-docs/-/blob/main/index.md)，本项目标注 MangaDex 来源和汉化组，不出售 API 内容、不加入广告。尊重站方和汉化组移除请求；维护者收到请求后应移除相关访问配置或过滤该作品/组，公开联系方式使用仓库 issue。API 已移除、不可用、站外章节不会作为可读内容显示。
