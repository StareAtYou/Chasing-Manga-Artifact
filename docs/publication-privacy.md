# 公开仓库脱敏与功能保留

本轮仅调整 Git 发布内容、忽略规则、公开说明和未发布提交的身份元数据。漫画源、解析器、网络会话、搜索关联、阅读器、下载、通知、存储、测试与部署下限保持原实现。

## 公开内容与本地内容

公开源码使用通用签名设置和 GitHub 公开提交身份。个人 Team、Apple 账户、证书/私钥、设备授权标识、描述文件、设备专用 IPA、导出日志、数据库、缓存和环境变量文件留在本机；本机 Xcode Team 设置继续可用，不会因为脱敏删除签名材料或已安装应用。

`.gitignore` 排除交付目录、安装包、常见签名文件、导出选项、数据库及环境文件。忽略规则只是降低误提交风险，维护者仍需检查显式添加和已跟踪的文件。不要使用 `git add -f` 上传这些本地材料。

测试里的固定 Cookie、请求头、示例地址和签名参数是合成测试输入；生产代码中的 Cookie/会话处理也是必要功能。不能通过删除这些字符串来替代凭据审查。

## 历史处理

扫描跟踪文件及尚未发布的全部历史后，将未发布提交里的本机邮箱和局域网地址替换为 GitHub 公开身份，保留提交内容、顺序和时间。设备专用签名有效期和 IPA 校验值仅保留在本地交付说明，公开记录说明验证方法与边界。已发布的远程提交保持不变，发布使用普通快进推送，不强制覆盖远程历史；原本地历史保留可恢复备份，不随推送公开。

## 验证

- 核对 151 个功能实现、测试与构建清单文件，内容哈希保持不变。
- 原生共享测试 22 组通过，便携共享检查 117/117 通过。
- Xcode 16.4 下 macOS / iOS 原生 Release 构建通过，iOS 本机开发签名继续通过校验。
- 忽略规则实际检查覆盖环境文件、签名材料、设备安装包、导出选项与本地数据库。
- 完整待发布历史和导出的源码文件使用 Gitleaks 8.30.1 扫描，均为零凭据发现；敏感标识与提交身份检查通过，完整报告仅保留在本机。
- iOS 17 / macOS 14 的运行下限不变，现有 macOS 15.7.7 与 iOS 18.5 系统不升级。

扫描结论只针对检查范围，不能保证未来维护者不会提交新的敏感内容。每次公开前仍应检查工作区、暂存区、提交历史和安装包授权信息。
