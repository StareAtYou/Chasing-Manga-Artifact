# v0.3.2 包子漫画解析修复

包子漫画 org 的目录接口为插入章节使用小数排序值。当前真实《武炼巅峰》目录含 3675.1、3718.1 等值；旧解析器把 order 声明为整数，导致整个目录解码失败，报“包子漫画目录格式不匹配”。现使用 Double 保留完整顺序，不向下取整、不丢弃番外章节，章节 URL 和连续 ordinal 保持原有语义。

原站的列表仍包含已下架作品，详情用 h1 内“章節下架”状态标识且不提供目录。此前误报结构不匹配，连续失败可能使已绑定来源需要重新检测。现区分作品下架和源结构变化，在详情、刷新目录及正文解析时明确提示“原站已下架这部漫画的章节，请选择其他漫画来源”，不计入来源结构失败。不会自动跳转到页面推荐的其他网站，真正的结构异常仍保留原有错误检测。

上述检查只覆盖样本目录和首尾正文资源，不代表全站所有作品已验证。原站已下架的内容无法由解析修复恢复。若旧版已经把来源标记为需要重新检测，请在源管理中用仍可读的作品重新检测；本版不擅自恢复未经验证的绑定。

四个回归检查分别覆盖小数排序的插入章节、下架不损伤源绑定、已保存作品目录下架、正文下架，均观察失败后再修复通过。共享检查177/177，Swift Testing原生入口31个通过。版本0.3.2、构建8，最低系统仍为macOS14/iOS17，使用Xcode16.4和iOS18.5 SDK，不升级设备系统。原有分类折叠、书架和下载行为保留。
