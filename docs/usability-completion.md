# v0.2.0 可用性补全与交付记录

2026-10-02，沿用用户已确认的双端本地设计与串行执行方式。macOS 的普通 Release 应用已运行并验证真实网站；iOS 原生构建、签名安装和启动随后已补齐，详见 [iOS 交付记录](ios-delivery.md)，其中明确保留未执行的交互检查。

## 修复与功能入口

- 新启动自动检查三站的浏览/搜索能力，缓存浏览作品。使用来源自己携带的作品验证搜索，保留曾经验证的能力；验证页和访问错误明确显示。
- 真实封面、作者、简介、章节数、更新时间；作品打开复用文档，DM5 导航不混入作品，瓜子标题不携带封面后缀。
- 多源搜索、搜索关联、从已经打开的作品手动选别名、通过作品链接核对后关联；始终由用户确认。关联保留各来源独立目录和进度。
- 书架详情/更换来源、续读、历史、移出书架停止关注；选择来源在阅读前保存。
- 章节筛选、最新/最早排序、批量选择与下载准备进度/取消、离线标记；下载任务显示作品名、来源、页数、失败原因与重试。
- 下载按钮重试已失败/暂停任务而不重复建立任务。新下载使用已解析地址，重试和重启刷新签名；下载准备与封面请求让位于正文。
- 下一章按章节身份重建阅读器；最后位置串行记录，退出/模式切换等待保存。
- 更新错误持久保存，空目录保留旧基线并报告错误；后台检查完成刷新界面，阅读新章/手动标为已读只清除对应更新。
- DM5 检测只请求首末页并保留真实总页数，遵守请求预算；实际读取正文仍逐页获取当前接口地址。
- 图片解码使用 8 Mi 像素预算与分块显示，预算内窄长图保留宽度；64 MiB 是解码缓存预算，不是应用总内存上限。
- 两个图片消费者共享请求时，取消一个不会打断另一个；已取消任务不会被新消费者继续复用。
- 自定义源先保存配置身份再检测，取消/重试使用同一配置；取消清理完成前不启动第二次检测。

## 共享验证

最终 `swift run MangaChecks`：117/117，含本轮 24 项可用性检查。可运行 `swift run MangaChecks --filter UsabilityTests` 单独复测。

行为 RED 包括首次搜索不可用、最后位置丢失、DM5 检测预算、重复请求、元数据、长图清晰度、新下载重复解析、图片取消竞争、空更新误报、失败任务不重试、列表导航/封面/标题、固定搜索样本误判、封面占用阅读优先级。新增关联/批量/API 先确认接口缺失，再验证完整状态与持久化；接口编译失败不冒充运行时失败。

## 普通 Release macOS 实机流程

环境：Apple Silicon、macOS 15.7.7、Swift 6.2.4/CLT。无 `--ui-testing` 参数，不使用原创测试夹具。应用为 App Sandbox + network.client 的本地临时签名包。

| 流程 | 结果 |
| --- | --- |
| 空数据启动→发现 | 真实浏览作品显示；瓜子/DM5可搜索；漫画站验证失败说明可见 |
| 瓜子搜索“一人之下”→详情→目录 | 实际封面、作者、简介，812章 |
| 第1章→下一章 | 窗口与正文切换至“第2话 2.姐姐2”，18页 |
| 逐页第2页→返回书架→退出重启→续读 | 恢复第二章第2页及逐页模式 |
| 第一章下载 | 完成18/18页，约2.9MB |
| 停用瓜子来源→离线阅读 | 第一章真实正文仍显示；测试后恢复启用 |
| 瓜子源检测 | 1作品/2章/真实首末预览；有限验证绑定持久保存 |
| 漫画站“非人哉”→最新章 | 991章；沙盒内WebKit取正文，最新章4页真实显示 |

这些是当前网络与选定作品的结果，不能推广为所有作品、所有地区永久可用。首次启动不包含测试书架/历史/离线漫画；验收产生的本机资料不会放入安装包。

## 自定义源界面追加验收

另用相同 Release 二进制及独立沙盒标识，向只绑定 127.0.0.1 的临时 HTTP 服务添加新网址，不改变生产应用资料。服务内容为现场代码生成的原创图片、两个作品及各两章，不是三站在线结果的替代。

“添加源”不提供样本→应用自动尝试固定方法→显示“解析成功并已绑定，2部作品/4章”→打开作品使用已保存绑定→批量选择两章→两个独立任务各2/2页下载完成。HTTP日志确认随后打开只读取所选作品，未重新验证另一作品。验收进程和临时服务结束，夹具/沙盒资料不进入交付包。

最终通用包复测：下载按钮在辅助功能树中独立可操作；下一章确实切换标题与正文；浏览标题去除封面后缀；关联界面支持已打开作品、来源详情链接与确认/取消。
