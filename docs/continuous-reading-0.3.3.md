# v0.3.3 连续跨话阅读

2026-10-07，版本 0.3.3，构建 9。继续兼容 macOS 14+、iOS 17+；本机 macOS 15.7.7 与连接设备 iOS 18.5 不需要升级。

## 使用方式

在阅读设置中选择“纵向滚动”。接近尾页时准备下一话，继续下滑即可阅读；在首页向上滑动，上一话末尾会接入顶部。章节之间有简短标题分隔，不切换到新的阅读页面。逐页、双页和手动章节选择保留原有操作方式。

菜单栏的章节名称、页数、上一章/下一章入口跟随当前阅读页面。一般以视口中部所在页为准；在顶部或底部继续滑动时，识别相应边界页，支持很短的章节和长短页面混排。

加载相邻话不提前改变历史或标记已读；可见阅读页面进入相邻话后才更新进度。切换模式、退出或重新打开时保留实际阅读话、页和页内位置。

## 加载与离线行为

相邻话使用当前选择的漫画来源和目录顺序。已经下载完成的话优先从本地读取；缺失的相邻话需要来源能够提供正文。加载失败在相应章节边界显示原因和重试，保留当前内容，不自动跳过受限章节。

顶部插入内容时使用可见页面锚点保持视野，避免直接跳到上一话首页。滚动中保留最多三话的活动窗口，移除远处话的解码缓存；向回阅读时可以重新准备这些话。短于一屏的内容通过真实的上/下滑动触发衔接，避免自动遍历整个目录。
