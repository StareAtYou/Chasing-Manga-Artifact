# v0.3.4 连续阅读过渡修复

章节插入、回收和图片真实高度变化时，保留当前可见位置，避免先跳到页首、再延迟恢复导致的闪动和回滚。维持 iOS 17+ / macOS 14+ 最低版本，兼容现有 macOS 15.7.7 / iOS 18.5，使用 Xcode 16.4 构建，不升级设备系统。

## 调整

- 连续阅读使用原生滚动容器与明确的行高度，内容变更和对应的位置补偿在同一布局过程中完成；不重建阅读路由，不触发章节衔接中的延迟 `scrollTo`。
- 插入上一话、回收旧章节时，同步计算可见图片的显示范围，保留已显示的图片，避免短暂空白；仅加载视野附近的图像。
- 图片解析出真实宽高后，补偿其对后续页面位置的影响。加载、失败及重试提示保持固定区域高度。
- 通常保留三个章节；短章节同屏显示时暂时保留仍可见的章节，滑出视野后再回收，避免删掉正在显示的内容。
- 不将原生回弹距离转换为永久空白；短章节向前插入时保留必要的滚动空间。macOS 按滚动条实际占用宽度排版，常驻滚动条不触发宽高反复变化。
- 初次打开、切换阅读模式和键盘翻页仍恢复对应页面位置。章节标题、阅读记录、离线文件、下载与漫画源解析保持原有行为。

## 验证

- 194/194 项共享行为检查通过，包含插入与回收不触发位置恢复、精确位置补偿、图片高度变化、可见图像保持、短章节保护与回收、回弹距离处理；新增回归检查在修复前已失败。
- `swift test` 的 31 个参数化测试入口通过；其覆盖范围与共享检查并非简单相加。
- 独立本地样本使用实际原生阅读器，在 macOS 上验证长章节双向衔接、延迟图像加载、多个短章节同屏与正反方向滚动。样本不接触用户书架、历史或账号。
- macOS 通用安装包与 iOS Release/IPA 原生构建及签名校验通过。iOS 18.5 真机已覆盖安装并成功启动 0.3.4，后续检查确认仍在运行。真机快速拖动、惯性与回弹的视觉体验仍需人工验收，不能由位置计算检查替代。
