# v0.3.0 书架与推荐

导航为书架、推荐、发现、更新。发现保留跨源搜索、搜索范围、作品链接和源管理，来源管理卡片不再占据首页。

书架可筛选全部、已离线、下载中；顶部和作品卡片均可打开下载管理，继续使用暂停、重试、取消、删除和离线阅读。单章、批量、整部下载自动让作品入架，复用已关联作品，不自动关注更新。旧下载启动时迁移至书架，包括停用来源。

移出书架前会提示：删除所有关联来源的任务与离线图片，保留阅读历史与进度。删除同时作废旧的下载准备请求并取消正在传输的图片，防止旧请求稍后重新入架。

推荐采用大卡片、封面列表、分类和来源专栏。排行榜保持原站顺序，没有榜单的来源显示浏览内容；不编造综合排名、分数和阅读量。分类来自来源实际导航/API，进入后读取真实分类页；只有原站可支持的排序和下一页才出现。用户继续自行选择阅读来源，同名作品不会自动合并。

来源请求各自隔离，失败不会清空其他源。成功快照本地保存，刷新失败的来源内容明确列在“上次保存的内容”；失效、停用和修改配置的来源不会继续发布旧响应。分类封面缺失时显示占位。

## 本地验证与兼容

新增合约覆盖下载自动入架、关联来源清理、在途准备与传输取消、旧下载迁移、真实分类/排序/分页、拒绝越源与任意分页链接、配置变更和部分源失败。原生样本界面验证推荐、分类翻页、作品详情、书架下载弹窗、离线阅读及移出提示，样本为本地原创内容。

最低系统保持 macOS 14 / iOS 17。版本 0.3.0，构建号 6；使用 Xcode 16.4 的 macOS 15.5 / iOS 18.5 SDK，不安装新系统或模拟器。源码与公共交付记录不包含开发 Team、设备标识或签名文件。

iOS 开发签名有效期以交付目录的 package-info.json 为准，免费 Personal Team 的期限由 Apple 决定，更新版本不能绕过此限制。手机正文交互需与构建、签名、安装和启动验证区分。
