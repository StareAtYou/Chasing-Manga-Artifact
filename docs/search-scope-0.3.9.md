# v0.3.9 发现搜索范围

版本：0.3.9（build 17）。保持最低 iOS 17 / macOS 14，使用 Xcode 16.4 构建；无需升级现有 macOS 15.7.7 或 iOS 18.5。

## 使用方式

发现页面顶部常驻显示“搜索范围”。默认选择“全部漫画源”，点击后可选择某一个漫画源；菜单中的“自定义多源…”保留原有多源筛选，并提供全选、清空选择。

输入关键词后逐步显示各来源结果，结果卡片继续标明来源。切换搜索范围会沿用当前关键词，清空旧结果和错误，并取消上一轮搜索；上一轮迟到结果不会混入新范围。选择在当前会话中保留，重启应用恢复默认全部来源。

只搜索已启用且具备搜索能力的漫画源。内置适配器声明支持搜索时，启动检测遇到网络失败或网站验证不会永久隐藏该来源；用户仍可选中重试，验证或访问错误按来源显示。未绑定且没有搜索能力的自定义来源不参与搜索。已停用或删除的单源选择会显示不可用，需要用户主动切换范围，不会自动扩大搜索。

## 验证范围

新增行为检查覆盖全部来源与单源切换、同关键词切换时的迟到结果、停用来源、空范围、自定义多源筛选，以及未完成启动检测的内置来源。共享回归检查 248/248 通过；Swift Testing 的 38 个入口通过（两者有重叠，不能相加）。macOS 使用独立本地原创样本实际操作，核对全部来源 6 条 → 单源 3 条 → 全部来源 6 条，并验证自定义范围；不读取个人书架。

Xcode 的 macOS UI 测试运行器在启用自动化模式时超时，iOS UI 测试因当前 Xcode 的 iOS 18.5 平台识别问题未能进入用例。这两项不计为通过；macOS 界面由直接原生操作验收，iOS 采用 SDK 18.5 的实际目标构建、签名、覆盖安装与启动检查，不宣称已完成 iPhone 搜索界面的自动化交互测试。

网站本身的验证要求、失效图片和网络访问限制保持原有提示，相关情况见 [漫画源接入说明](duokan-fengche-0.3.8.md)。
