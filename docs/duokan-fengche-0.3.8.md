# v0.3.8 多看漫画与风车漫画

版本：0.3.8（build 16）。最低 iOS 17 / macOS 14，使用 Xcode 16.4 构建，兼容现有 macOS 15.7.7 / iOS 18.5，无需升级系统。

## 接入范围

- 多看漫画：https://www.duokanmh.com/ ，包含用户指定的国漫入口 https://www.duokanmh.com/fenlei/area/guoman 。
- 风车漫画：https://www.fengchemh.com/ 。
- 新增稳定来源标识，原有九个来源标识保持不变。支持首页推荐、排行、细分分类、作品信息、完整章节目录、图片阅读与现有离线下载队列。
- 解析公开阅读页的数据格式，使用原生 AES 解码，不执行下载的 JavaScript。代码中的格式常量来自网站公开前端，不是用户账号密钥。
- 风车图片保留网站声明的中转地址；部分相对路径图片按网站格式解码。读取、来源检测、前台下载与原生后台下载共用解码流程，磁盘缓存保存普通图片；旧版任务缺少编码字段时仍可读取。
- 拒绝错站、错章节、无效图片数据与已下架作品；推荐分类排除“更多>”和章节标题等导航噪声。

## 验证

共享回归检查 242/242 通过；Swift Testing 原生入口 38 个通过（与共享检查有重叠，不能相加）。测试包含合成加密网页、独立生成的图片向量、搜索编码、验证页保留、分类过滤、原始中转地址、来源绑定，以及原生后台图片解码。

在 macOS 与连接的 iOS 18.5 真机上，通过实际适配器核对多看《斗破苍穹》681 话、风车《斩月》81 话；抽查首末章节的首尾图片。真机使用实际 ImagePipeline 和 BackgroundTransfer 完成代表图片读取和下载，图像尺寸与内容有效。本次没有逐话下载整部漫画，也没有宣称所有第三方章节永久可用。测试使用独立诊断容器，不修改个人书架。

## 已知来源限制

风车搜索目前会返回网站安全验证，应用保留验证提示；可在来源管理打开网站手动验证，再保存访问状态并重试，未完成验证时不会伪造搜索成功。

当前 Mac 的系统代理路径对风车部分图片中转域名返回 403，直连诊断及 iPhone 实测可以获取正文。应用遵循用户系统网络设置，没有自动更改或绕过代理；若遇到相同问题，需要检查现有代理路由或切换可访问的网络。不能将中转地址解包成原始图床链接，原始链接可能返回防盗链提示图。

风车《魔皇大管家》页面合并了多个旧版本目录，抽查的旧版本图片返回 404。该情况保留章节不可访问提示，不把网站失效图片判定为已修复。

## 隐私与安装

仓库只包含合成测试夹具，不提交真机书架、网站 Cookie、签名 Team、设备标识、描述文件或诊断图片。iOS 安装包采用当前设备开发签名，有效期以安装包旁的 package-info.json 为准；签名有效期受 Apple 签发配置限制。
