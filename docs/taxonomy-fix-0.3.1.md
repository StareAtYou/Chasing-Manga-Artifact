# v0.3.1 分类规范与折叠

“按分类发现”默认收起。点击整行标题展开，再次点击收起；显示分类数量与展开状态，展开后仍进入真实分类专栏。

修复分类路径被过度信任的问题：分页按钮、纯数字页码、连载/完结状态、排序、更多入口和符号按钮不再作为类别。ComicFury 跳过“+”添加按钮，取实际标签文字。常见英文类型转换为对应中文，繁简规范化，同一来源内的重复分类合并；保留“怪谈”等真实来源特有类别，不用封闭白名单删减未知题材。热门漫画入口归入榜单，保留原来的分类翻页功能。

已保存的推荐快照在读取时同步规范分类，保留有效作品，网络暂时失败也不会重新显示旧的分页伪类别；旧 ComicFury “+”缓存可根据声明标签查询恢复名称。
