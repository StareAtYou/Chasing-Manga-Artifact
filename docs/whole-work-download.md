# v0.2.3 整部漫画一键下载

在作品详情的每张来源卡片或所选来源的章节页点击“下载整部漫画”。应用刷新该来源的最新完整目录，随后进入下载页，逐章取得正文地址并加入现有下载队列。章节页的关键词筛选和“最新在前”排序不会限制整部下载范围；其他关联来源的章节不会混入。

- 下载点击当时已发布且可读的章节，跳过付费、登录、地区限制等已标记不可读章节。未承诺连载作品未来章节自动下载。
- 已完成或正在等待/传输的章节不重复下载，失败或暂停的已有任务继续使用原任务补齐。已取消任务可以重新建立。
- 单章正文解析失败会列出章节名称与具体原因，随后继续处理其他章节；目录刷新失败则明确提示，不将旧目录当作完整目录下载。
- 下载页区分“目录处理 / 取得地址 / 加入队列”与各章真实图片传输进度。取消准备只停止尚未入队的章节，已入队任务可在下载页分别暂停、取消或重试。
- 目录和正文地址准备在应用运行时执行。关闭应用可能中断尚未入队的准备；重新点击“下载整部漫画”会刷新目录、跳过已有任务并补齐。已入队任务沿用原有持久化与重启恢复机制，iOS 后台传输仍受系统调度约束。
- 不覆盖已有离线图片、阅读进度、书架或来源配置，不增加账号、同步服务或漫画数据分发。

## 验证

六项新增共享检查覆盖：刷新完整目录与真实离线图片；付费跳过、单章失败继续和失败标题；重试去重；关联来源隔离；快速重复点击与取消；暂停及失败原任务恢复；停用来源拦截。核心检查与失败标题断言均先观察失败再实现通过。验证使用本地原创 PNG 和受控目录，不批量下载网站漫画。

- 完整共享检查 155/155 通过，Swift Testing 28 个测试入口通过。
- macOS 本地样本界面：从来源卡片点击一次，2 章各 4 页实际下载完成并打开离线正文；再次点击显示已有 2 章，未新增任务。
- macOS Release 包包含 arm64 和 x86_64，签名校验通过；本机界面验收为 Apple Silicon。
- iOS 18.5 真机：新版 v0.2.3 / build 5 覆盖安装与进程启动均成功，设备应用清单确认版本 0.2.3；IPA 内二进制与安装的构建产物一致。手机上的整部下载触控、正文阅读和后台持续下载尚未单独验收。
- 用户大目录的性能与内存尚未实测；本版沿用原有逐章准备、下载并发和持久化机制。

发布时使用 Xcode 16.4 和 iOS 18.5 SDK，最低 iOS 17 / macOS 14，保持用户设备 macOS 15.7.7 和 iOS 18.5 不变。设备专用 IPA 的期限仍由 Apple 实际签发的描述文件与证书共同决定，整部下载不会改变签名期限。
