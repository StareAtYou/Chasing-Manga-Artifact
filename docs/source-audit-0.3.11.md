# 漫画源检查与修复（0.3.11 / build 19）

检查日期：2026-11-09。使用 Xcode 16.4，在 macOS 15.7.7 上运行真实适配器。每个已实现来源抽取一个作品的完整目录、首末章页面列表，并请求首末图片进行解码；同时检查浏览、搜索、推荐分类与分类分页。这是代表性样本检查，不代表所有作品、所有章节均正常，也不能替代 iPhone 网络环境的逐源验证。

## 修复

- 多看《一人之下》详情页（`https://www.duokanmh.com/manhua/emy8bAg1NJ`）明确显示“该漫画已下架，请阅读其他作品”。现在报告原站下架并提示选择其他来源，不再误报“缺少完整章节目录”。检测限定在原站的 `.chapter-list-empty-tips` 状态区域，普通简介、广告或其他作品文字不影响判定。
- 多看阅读器的当前公开脚本直接使用完整图片 URL，仅对相对路径应用图片中转及 Base64 编码。修复完整 URL 被再次包装的问题；遵循数据中的 `no_referrer` 设置。保留章节、作品、来源身份校验。
- 瓜子首页旧 `tag` 分类入口现会跳转到数字 `cid` 地址。推荐分类从原站分类目录发现当前规范入口，保留首页推荐内容，不放宽分类、排序或分页的跳转校验。线上分类首、第二页均取得 36 部作品。
- SourceProbe 新增 `--audit` 自动选取首页样本，并在报告中保留实际样本网址，方便重复检查。
