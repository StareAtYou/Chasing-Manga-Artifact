# v0.3.10 新增漫画源

版本0.3.10（build18），使用Xcode16.4，最低iOS17 / macOS14。保留原有来源身份、书架、阅读记录与离线资料。

在已有多看漫画之外，新增77漫画（https://www.77hh.net/）与好看漫画（https://www.haokantxt.com/），适配其公开网页格式。古古漫画（https://www.gugu5.com/）当前连接失败，作为待验证来源保留，不宣称已支持正文解析。

《斗破苍穹》目录的完结篇不保证所有中间章节无缺漏。两个来源可能使用相同的图片上游，不能视为完全独立的图片备份；访问或原站验证错误保留明确提示。

本次先为原应用生成新签发的7天描述文件，确认期限后覆盖安装；来源更新完成后再次覆盖安装新版。个人签名此次签发至2026年11月7日18:02（北京时间），以安装包旁的签名信息为准。开发Team、设备标识、描述文件、真机资料和诊断图片均不纳入源码提交。

## 验证

共享检查255/255通过，Swift Testing39个入口通过（两者有重叠）。实际Mac来源探测取得两个来源各680个目录条目；抽查首末章节图片解码、搜索与分类浏览。两个站点目录并不等同于无缺漏全本，仍需留意原站缺章。共享图床可能返回429，沿用现有重试与并发调度处理。

古古原HTTPS地址TLS连接失败，HTTP访问会跳往另一域名的明文页面；没有自动改用未经验证的新域名。

iPhone iOS18.5独立诊断容器使用实际适配器、ImagePipeline及BackgroundTransfer，两个来源首末章节的首尾图片及代表图片下载均成功，返回200并可解码。该验证为代表样本，不是逐话下载整部作品。
