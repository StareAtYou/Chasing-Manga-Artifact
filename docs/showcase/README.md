## 采集方式与数据

macOS 图片来自 macOS 15.7.7 上运行的原生应用窗口；iOS 图片来自 iOS 18.5 真机应用的原生窗口渲染。两端均使用项目实际的 SwiftUI 书架、推荐、详情和阅读器视图。为展示排版，使用独立演示构建和临时本地数据库，未改动正式应用功能或已有用户资料，也未升级设备系统。

漫画源 A/B、作品名称、推荐和排行均为演示数据，来源网址使用 `.invalid` 保留域名。封面与漫画页面通过本地绘图代码生成，为本项目原创插画，不含第三方漫画正文。图片展示界面功能，不代表线上来源的实际排行或可用性。

## 信息脱敏与许可

仅采集应用窗口，不包含桌面、通知、真实设备名称、设备标识、签名 Team、账号、Cookie、个人书架或本地文件路径。已移除图片中的 EXIF、IPTC 与文本元数据，并验证像素内容保持一致。构建记录、临时演示工程、签名材料和演示数据库不随这些图片发布。
